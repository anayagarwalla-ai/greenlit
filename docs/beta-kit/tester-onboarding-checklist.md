## Before invitation

- [ ] Production health reports `readyForBeta: true`.
- [ ] Operator identity, monitored support email, address, governing law, and venue are configured.
- [ ] Agency business email is on the beta allowlist.
- [ ] Agency has received the beta handbook and data restrictions.
- [ ] Agency understands that Greenlit is not a contract, formal signature service, ledger, certification, or payment guarantee.
- [ ] Agency has selected a public HTTPS staging origin it controls.
- [ ] Project contains no prohibited or regulated information.
- [ ] One primary agency contact and one client decision-maker are identified.

## Guided onboarding

- [ ] Tester opens the synthetic guided demo.
- [ ] Tester identifies the failed `launch-rc1` form result.
- [ ] Tester verifies the passing `launch-rc2` example.
- [ ] Tester completes the sample client decision.
- [ ] Tester can explain the difference between a correction and possible new scope.

## First real milestone

- [ ] Scope is limited to three to six criteria.
- [ ] Every criterion has a supporting source quote.
- [ ] Agency confirms the criteria and typed mappings.
- [ ] Staging ownership is verified.
- [ ] Retained run completes or the exact blocker is recorded.
- [ ] One client review is created with a clear deadline.
- [ ] Private link and access code are shared separately.
- [ ] Decision is recorded or abandonment reason is captured.
- [ ] Invoice-ready or configured invoice result is checked.
- [ ] Agency can retrieve the retained record.

## Follow-up

- [ ] Feedback interview scheduled.
- [ ] Product issues entered without client content.
- [ ] Outcome metrics added to the scorecard.
- [ ] Publicity permission recorded separately.
- [ ] Next milestone or exit decision agreed.
