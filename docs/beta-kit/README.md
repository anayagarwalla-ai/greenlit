# Greenlit beta operating kit

This folder contains the internal materials needed to run a small, evidence-driven agency beta.

## Use in this order

1. Complete `tester-onboarding-checklist.md` for each agency.
2. Track cohort status in `beta-account-tracker.csv`.
3. Record product outcomes in `beta-success-scorecard.csv`.
4. Run `interview-script.md` after a tester completes or abandons the workflow.
5. Summarize the cohort with `weekly-feedback-summary.md`.
6. Classify problems using `issue-severity-rubric.md`.
7. Use `inactivity-follow-up.md` when a tester stalls.
8. Use `case-study-capture.md` only after obtaining separate publication permission.

## Materials that need an accountable human

- `pricing-decision-worksheet.md` prepares the beta and post-beta pricing decision. It does not choose a price.
- `office-hours-runbook.md` prepares a repeatable session. An operator still needs to choose and attend the time.
- `video-production-checklist.md` works with the public two-minute demo script. A person still needs to record and approve the final video.

Do not place client SOW text, credentials, review access codes, or regulated data in these files.
