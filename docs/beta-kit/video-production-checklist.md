# Blueprint 2:45 demo video production checklist

Use with `docs/JUDGE_DEMO.md`. The official submission window is 2–5 minutes; target 2:30–2:55.

## Before recording

- [ ] Production deployment and synthetic demo are healthy.
- [ ] Browser contains no personal bookmarks, extensions, notifications, or unrelated tabs.
- [ ] No client or production customer data appears.
- [ ] Recording resolution is 1440 × 900 or 1920 × 1080.
- [ ] Browser zoom is 100 percent.
- [ ] Cursor size and motion are visible but not distracting.
- [ ] Microphone test is clear.
- [ ] Final script reflects the current product.

## Required shots

- [ ] Homepage proof card.
- [ ] Synthetic SOW import.
- [ ] Exact source quotes and agency confirmation.
- [ ] Typed checks.
- [ ] Failed `launch-rc1` form result.
- [ ] Passing `launch-rc2` result.
- [ ] Client review.
- [ ] Approval receipt.
- [ ] Invoice-ready state and closing card.

## Editing

- [ ] Final length is 150 to 175 seconds.
- [ ] Captions are accurate.
- [ ] No em dash is used in on-screen copy.
- [ ] No unsupported security, legal, accessibility, payment, or performance claim appears.
- [ ] Synthetic data is labeled.
- [ ] Any music is licensed for the intended use.
- [ ] CTA points to the correct beta destination.
