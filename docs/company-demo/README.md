# Greenlit company-demo kit

Use this folder as the operating package for conversations with prospective design partners. The product walkthrough is synthetic by default. A real retained transaction is a separate production-readiness gate, not a live-demo dependency.

## Before outreach

1. Complete every item marked **Founder required** in `operator-action-checklist.md`.
2. Review the non-secret provider evidence in `provider-readiness-2026-07-26.md`.
3. Run `pnpm demo:preflight`, then the validation commands in `production-demo-smoke-checklist.md`.
4. Rehearse `20-minute-runbook.md` twice with the reliable synthetic path.
5. Approve one offer in `design-partner-offer-draft.md`.
6. Personalize `post-demo-follow-up.md` for the company and attendee.

## Ready-made collateral

- `deliverables/greenlit-company-demo-deck.pptx` — editable eight-slide company-demo deck using only Greenlit’s synthetic product screens.
- `deliverables/greenlit-one-page-brief.pdf` — tagged, printable one-page leave-behind. Keep its `.source.json`, `.html`, and `.print.css` files for later edits.
- `deliverables/greenlit-company-demo-fallback.mp4` — silent 40-second, 1280×720 H.264 fallback assembled from the reviewed deck. It is usable when the live walkthrough is unavailable, but it does not replace the founder-approved narrated recording in `fallback-video-shot-list.md`.

## During the meeting

- Start with discovery. Do not paste a prospect's SOW or client data into the demo.
- Use `/workspace?demo=guided`, `/review/demo`, and `/receipt/demo`.
- Call the walkthrough synthetic and not retained every time that distinction matters.
- Do not promise protected-preview support, certifications, integrations, payment outcomes, or universal site compatibility.

## If anything is unstable

Stop the affected capability using the private operator controls. Continue only with the synthetic walkthrough and the approved screenshots. Never improvise a real client-data test during a sales call.
